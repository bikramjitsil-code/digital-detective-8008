# Mission 1 — Know your computer

## 1. Task / objective

Explain how a computer receives input, processes information, produces output and stores results. Identify hardware, software and computer-based systems used in everyday life.

## 2. Work completed

### Task 1.1 — Trace an activity using IPOS

Chosen activity: Typing and saving a document.

| Stage | What happens in my example? | Hardware / component |
|---|---|---|
| Input | I press keys to enter text and use the trackpad to select options. | Keyboard and trackpad |
| Processing | The processor runs the editor's instructions and handles the text. RAM holds information needed while the application is running. | CPU and RAM |
| Output | The document and the changes I make are displayed on the screen. | Display |
| Storage | When I save, the document is written to storage so I can reopen it later. | SSD |

The activity starts with keyboard input. The computer processes that input and displays the text. Saving stores the document for later use.

## 4. My understanding

IPOS stands for input, processing, output and storage. These stages explain how a computer accepts information and produces useful results.

Hardware consists of physical components. Software consists of instructions and programs that tell hardware what to do.

RAM supports work while programs are running, while an SSD stores files for later use.

Computer systems are not limited to laptops and phones. Devices such as ATMs and ticket machines also process inputs and produce outputs.
